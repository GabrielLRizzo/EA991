# Atividade 01 - Classificação Linear

## Objetivos
- Trabalhar com uma base de dados com atributos categóricos e faltantes;
- Consolidar uma metodologia completa de aplicação de um modelo de *machine learning* a um problema prático;
- Analisar de diferentes modos o desempenho de um classificador numa instância de classificação binária.
  
## Conjunto de dados

Disponível no UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/73/mushroom

![](https://storage.googleapis.com/kaggle-datasets-images/478/974/557711140aeab7ca242d1e903c4e058e/dataset-cover.jpg)

## Procedimento de entrega

1. Faça um *fork* do repositório 'Atividade_01' para a sua conta;
2. Abra o *notebook* 'roteiro_atividade_01_EA991_1s2025' e desenvolva a sua solução para os itens propostos;
3. Ao terminar de resolver a atividade, faça o *upload* do *notebook*, renomeado conforme o padrão atividade_01_numero_RA.ipynb, no diretório 'solucao' dentro do repositório.
   - Google Colab: Arquivo -> Salvar uma cópia no Github -> Selecione o repositório (o *fork* criado). No campo "caminho", coloque "solucao/atividade_01_numero_RA.ipynb" para que o *notebook* seja colocado no diretório desejado.
